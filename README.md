## 📌 Hakkında / About

[🇹🇷]  Bu depo, Go dilinde yazılmış [Hugo](https://gohugo.io/) site derleyicisi ile geliştirilmiş, GitHub Pages üzerinden yayınlanan kişisel portföy/özgeçmiş sitesinin kaynak kodunu barındırır.
Site; inşaat mühendisliğinden yazılım geliştirmeye, yapay zekadan siber güvenliğe uzanan çok disiplinli bir kariyeri tanıtmak amacıyla tasarlanmıştır. İçerik **Türkçe** ve **İngilizce** olmak üzere iki dilde sunulmaktadır.

[🇬🇧] *This repository hosts the source code of a personal portfolio/resume website, built with the [Hugo](https://gohugo.io/)  site generator (written in Go) and published via GitHub Pages.*
*The site showcases a multidisciplinary career spanning civil engineering, software development, artificial intelligence, and cybersecurity. Content is available in both **Turkish** and **English**.*

## 📁 Klasör Yapısı / Folder Structure

```
.
├── ai/              # Yapay Zeka bölümü içerikleri     · AI section content
├── blog/            # Blog yazıları                    · Blog posts
├── css/             # Stil dosyaları                   · Stylesheets
├── en/              # İngilizce site içerikleri         · English content
├── tr/              # Türkçe site içerikleri            · Turkish content
├── files/           # İndirilebilir dosyalar (CV vb.)   · Downloadable files (resume, etc.)
├── images/          # Görseller                        · Images
├── js/              # JavaScript dosyaları              · JavaScript files
├── software/        # Yazılım bölümü içerikleri         · Software section content
├── tags/            # Etiket sayfaları                  · Tag pages
├── webfonts/        # Web fontları                      · Web fonts
├── index.html       # Ana sayfa                         · Home page
├── index.xml        # RSS akışı                         · RSS feed
├── sitemap.xml      # Site haritası                     · Sitemap
├── robots.txt       # Arama motoru yönergeleri          · Search engine directives
├── 404.html         # Özel 404 sayfası                  · Custom 404 page
├── CNAME            # Özel alan adı yapılandırması       · Custom domain config
└── .nojekyll        # Jekyll işlemesini devre dışı bırakır · Disables Jekyll processing
```

[🇬🇧] The site is automatically deployed via **GitHub Pages** from the `main` branch. Thanks to the `CNAME` file, it is accessible through the custom domain **[abdulkadirgungor.com](https://abdulkadirgungor.com/)**.
